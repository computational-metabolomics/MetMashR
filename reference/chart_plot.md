# chart_plot method

Plots a chart object

## Usage

``` r
chart_plot(obj, dobj, ...)
```

## Arguments

- obj:

  a chart object

- dobj:

  a struct object

- ...:

  additiional inputs to chart_plot

## Value

a plot object

## Examples

``` r
C <- example_chart()
chart_plot(C, example_model())

#> NULL
```
